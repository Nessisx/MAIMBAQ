# Despliegue de MAIMBAQ

Esta sección documenta cómo hemos desplegado la aplicación MAIMBAQ en diferentes plataformas, desde los pasos que realizamos con Heroku hasta la migración a Azure.

## Plataformas de despliegue

- **Heroku** (Cómo lo hicimos inicialmente)
- **Azure** (Plataforma actual recomendada)

Elige la sección que necesites consultar:

- [Despliegue en Heroku](/docs/deployment/heroku) - Referencia histórica del proceso inicial
- [Despliegue en Azure](/docs/deployment/azure) - Proceso actual y recomendado

---

**Nota**: Aunque Heroku fue nuestra plataforma inicial de desarrollo, actualmente recomendamos utilizar Azure para producción, ya que ofrece mejor escalabilidad, integración con ecosistemas Microsoft y soporte empresarial.
