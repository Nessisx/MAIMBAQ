🤖 FEATURES DE POSEAI:
====================

Métodos de IA:
  1. MediaPipe Hands (método principal)
     - Detección de 21 landmarks de manos
     - Análisis geométrico de gestos
  
  2. Teachable Machine (fallback)
     - Modelo TensorFlow entrenado
     - 3 clases: Piedra, Papel, Tijera

Funcionalidades:
  ✓ Subir imagen
  ✓ Capturar foto
  ✓ Cámara en vivo con análisis real-time
  ✓ Confianza de predicción
  ✓ Información del método utilizado
